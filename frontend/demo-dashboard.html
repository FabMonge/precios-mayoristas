    Índice de una canasta de productos básicos

    El índice es la media geométrica de la variación diaria de los precios de todos los productos, encadenada desde el primer día (= 100), el método estándar para índices sin ponderar: evita que un solo producto que se dispara arrastre a todos los demás. No pondera por el consumo de los hogares. El Gran Mercado Mayorista no opera domingos ni feriados, por lo que esos días no se incluyen.

    ¿Cómo usar el buscador?

    • Escribe el nombre de un producto y elige una de las opciones.
    • También puedes tocar la flecha para ver la lista completa ordenada por tipo de producto.
    • Pulsa en cualquier producto de los gráficos de arriba para conocer el detalle.
    • Pasa el cursor o el dedo sobre la línea para ver el precio de cada día.
    • Los botones “Día, Semana y Mes” cambian el periodo de comparación.
